# v1.3.x series (next stable)

## v1.3.0 (upcoming release)

### Changed

* ⚠️ The settings framework migrates from
  [Dynaconf](https://www.dynaconf.com/) to
  [pydantic-settings](https://docs.pydantic.dev/latest/concepts/pydantic_settings/).
  `eradiate.config.settings` is now an {class}`.EradiateSettings` instance.
  Settings semantics are unchanged (same setting names, defaults, environment
  variables and settings file discovery). The canonical access idiom is now
  lowercase attribute access (*e.g.* `settings.data_path`); the dict-style
  `settings["some.key"]` and `settings.get("some.key")` idioms remain supported
  with case-insensitive dotted keys. Unknown settings now emit a `UserWarning`
  instead of being silently ignored.

### Fixed

* Invalid `rng_seed` setting values now raise a validation error with an
  explicit message instead of an unhandled `ValueError`.
