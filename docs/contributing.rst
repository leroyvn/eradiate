Contributing to Eradiate
========================

Eradiate welcomes contributions to its code and documentation. How to ask
questions, report bugs and submit pull requests is described in the
`contribution guide on GitHub <https://github.com/eradiate/eradiate/blob/main/CONTRIBUTING.md>`__.

.. important::
   Eradiate is written and documented in English using
   `Oxford spelling <https://en.wikipedia.org/wiki/Oxford_spelling>`__.

Where to start
--------------

1. Set up a development environment: :ref:`sec-developer_guide-install`, then
   :ref:`sec-developer_guide-workflow`.
2. Read the :ref:`coding conventions <sec-developer_guide-code>` and the
   :ref:`docstring conventions <sec-developer_guide-docstrings>`.
3. Find the procedure for your task in the :ref:`developer guide
   <sec-developer_guide>`.
4. To understand why a component is built the way it is, read its
   :ref:`design note <sec-design_notes>`.
